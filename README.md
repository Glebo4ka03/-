# Практикум: Обратное давление в Project Reactor

## Описание проекта

Данный проект — учебная работа по реактивному программированию.  
В нём исследуется проблема несоответствия скорости генерации и обработки данных, а также способ её решения с помощью механизма обратного давления (backpressure).

### Цель работы

Изучить, как стратегия `onBackpressureDrop` в Project Reactor защищает систему от переполнения памяти, когда производитель данных быстрее потребителя.

### Что делает программа

Программа проводит два теста:

1. **Тест 1 (без защиты):**  
   Генератор создаёт 1 элемент в миллисекунду. Обработчик тратит на каждый 90 мс.  
   Результат: быстрый поток данных накапливается в памяти, буфер растёт, что может привести к OutOfMemoryError.

2. **Тест 2 (с onBackpressureDrop):**  
   Та же скорость генерации и обработки, но включена стратегия отбрасывания.  
   Результат: лишние элементы (которые обработчик не успевает взять) сразу отбрасываются, память не переполняется.


### Вывод

Без обратного давления система рискует упасть с ошибкой нехватки памяти.  
Применение стратегии Drop позволяет контролируемо отбрасывать данные, сохраняя стабильность приложения.

## Навигация по репозиторию (как найти код)

Репозиторий содержит Maven-проект. Ниже описан путь к файлам и их назначение.

### Где лежит главный код

1. Откройте корневую папку репозитория `prac2`
2. Перейдите в папку проекта: `demo`
3. Далее пройдите по пути: `src` → `main` → `java` → `com` → `example`
4. Откройте файл `BackpressureDemo.java`

В этом файле находится весь код эксперимента. Каждая строка снабжена подробными комментариями на русском языке, поясняющими:
- Зачем нужен каждый импорт
- Что делает каждый метод
- Как работает реактивный поток
- Как собирается статистика

### Где лежит конфигурация Maven

Файл `demo/pom.xml` содержит:
- Зависимость `io.projectreactor:reactor-core` версии 3.6.2
- Настройки компилятора Java 17
- Плагин `exec-maven-plugin` для запуска программы
